# デザイン指針

サイトをどう見せるかの指針。何を載せるかは [site.md](site.md)。

## テーマ

**モノトーン、ミニマル、心地よさ、連続性。** 判断に迷ったらこの4つに戻る。

目指すデザインの系譜はディーター・ラムス、Nothing、teenage engineering。
機能から形が決まり、余計なものがなく、触れたときの手応えがある。

- **モノトーン。** 地は暗く、文字は白に近いグレー。色は写真だけが持つ。
- **ミニマル。** 写真が主役。写真以外は小さく、薄く、少なく。
- **心地よさ。** 静かで遅い。急がせない。見る人の速度に合わせる。
  現れるものは浮かび上がる。飛び込んでこない。
- **連続性。** 動きは「操作への反応」ではなく「流れ」。ページ内もページ間も途切れない。
  ホイールの入力を直接使わず、少し遅れて滑らかに追従させる。

## 動き

- 慣性スクロールを全ページの土台にする。
- **現れ方は wipe（下から現像するように）で仮決定。** 2026-10-01。写真の見せ方は masonry。
  候補を複数実装して比べた結果で、まだ比べる余地を残すため切り替えは残してある
  （dev 時のみ）。確定したら全ページで同じ現れ方に揃え、他の候補は消す。
- 消えるときは速く、現れるときは遅い。ホバーの反応は 0.3 秒程度。現れる動きは 1 秒を超えてよい。
- バウンス、横からのスライド、回転は使わない。
- `prefers-reduced-motion` では動きをすべて切る。

## 色と文字

- 地は `#101010`。純黒だと写真の黒と見分けが付かないのでわずかに持ち上げる。
- 文字は `#fdfdfd`。補助のラベルは 55% 程度に落とす。階調はこの2段階だけ。
- 書体は本文にサンセリフ。見出しに対になるセリフを使うかは未決。
  英字のラベルは小さく、字間を広げる。
- 線は 1px、白 10%。

## 写真

- 一覧は「選ぶため」、単体は「見るため」。役割を分け、単体は画面幅に近い大きさで見せる。
- 角を立てたまま、枠なし、影なし。
- 表示品質を落とさない。解像度・圧縮・トリミングの変更は本人に確認する。

## 実装

- ライブラリは最小限。慣性スクロールは小さなもの1つか自前。演出は CSS の
  transition・filter・mask と IntersectionObserver で作る。WebGL は hero と、
  画像の遷移が要る場面だけ。
- 演出は属性1つ（例: `data-reveal`）で付け外しできる形にし、ページごとに書かない。
