# デザイン指針

サイトをどう見せるかの指針。何を載せるかは [site.md](site.md)。

## テーマ

**モノトーン、ミニマル、心地よさ、連続性。** 判断に迷ったらこの4つに戻る。

目指すデザインの系譜はディーター・ラムス、Nothing、teenage engineering。
機能から形が決まり、余計なものがなく、触れたときの手応えがある。

- **モノトーン。** 地は暗く、文字は白に近いグレー。色は写真だけが持つ。
- **ミニマル。** 写真が主役。写真以外は小さく、薄く、少なく。
- **心地よさ。** 静かで遅い。急がせない。見る人の速度に合わせる。
  現れるものは浮かび上がる。飛び込んでこない。
- **連続性。** 動きは「操作への反応」ではなく「流れ」。ページ内もページ間も途切れない。
  状態の変化は「切り替わり」ではなく「移動」で示す。濃さや色を跳ばして状態を表さず、
  同じものが位置を変えて移る形にする。移るものは形を保ち、位置だけを変える。
  中身が入れ替わる場面では、入れ替わらずに残るものがその経路を見せる。
  一続きのもの（スクロール、時間）は、区切りではなく、連続した長さの中の現在地として見せる。

## まだ途切れているところ

連続性の指針に照らして、跳んでいる場面。対応したら消す。

- **ページの移動。** 中身が一瞬で置き換わり、スクロール位置も先頭へ瞬時に飛ぶ。
- **Photos のカテゴリの切り替え。** 一覧を作り直すので、写真がいったん全部消えて現れ直す。
- **フッターの左側。** ページを移ると、中身（再生操作・カテゴリ・空）が一瞬で入れ替わる。
- **ナビの下線の出入り。** トップと他のページのあいだで、滑らずに出現・消失する。
- **Photos のスクロールの線の出入り。** Photos に入った瞬間に現れ、出た瞬間に消える。
- **広げた写真の画質。** 小さい画像を引き伸ばした状態から、大きい画像へ一段で差し替わる。
- **戻ってきた写真。** 遠くで画像を外した写真に戻ると、読み込み直された画像が突然現れる。
- **トップの hero の出現。** JS が動くまで何も無い場所に、写真とカレンダーが突然現れる。
- **Photos の一覧の出現。** 一覧が届くまで空で、届くと一気に段組が組まれる。
- **画面の幅の境目。** 640px を境に、段組（3 列 ↔ 2 列）と hero（横並び ↔ 縦並び）が一瞬で組み替わる。
